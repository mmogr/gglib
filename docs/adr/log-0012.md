# ADR 0012 log

A dated log for [ADR 0012](0012-the-remote-tunnel.md) while the remote arc is open. Entries are appended, never edited. When the arc closes they are folded into the ADR as one dated note, rather than as further amendments to it during the arc.

## 2026-09-15: pairing moves to the tunnel edge

gglib now pairs through modelpipe 0.6. `ServeHandle::invite` mints the device's key and name and holds the key at the edge; gglib stores both, then arms the code; the edge answers `POST /modelpipe/pair` itself. The proxy no longer sees a pairing request, and `modelpipe::pair` on the joining side connects, waits for the far machine and only then presents the code.

**The correction history `docs/remote.md` carried, moved here.** Its paragraph "Pairing moves a one-time code, not the key" carried a block headed "Corrected 2026-09-07, and again 2026-09-12". What it recorded:

- On 2026-09-07 no one path had all three of the two-minute window, the burn at the third wrong code, and the ticket being needed. Over the tunnel a wrong code was a wrong bearer, refused at the edge before gglib saw it, so gglib's own counter never saw those guesses.
- Once the ticket started lasting, the edge counted wrong bearers itself (`grant_once_bounded`, three attempts), so over the tunnel the burn and the window both held, and the arithmetic stopped resting on a ticket that no longer changed.
- On the desktop's own loopback the burn counted, but `POST /v1/remote/pair` needed no ticket, so a local process could end a pairing that was on screen with three POSTs (gglib #1045).

With the code answered only at the edge, that hole is closed: the proxy's loopback pairing route is gone, so three POSTs no longer end a pairing. Wrong codes are counted per endpoint at the edge, three each, and anything holding the ticket, a local process included, can still end an invite by guessing from sixty-five endpoints, which this machine logs as burned. The paragraph in `docs/remote.md` now says what is true and points here, instead of adding a third correction beneath the other two.
