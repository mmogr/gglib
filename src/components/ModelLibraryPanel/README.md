# ModelLibraryPanel

<!-- module-docs:start -->

What the library's Add pane shows until the one search takes its place
(L2): the Hugging Face browser and the local-file form on two tabs, and the
model `gglib up` would suggest for this machine. The library itself, its
rows and groups, is `src/places/library/`.

## Key Files

| File | Role |
|------|------|
| `AddDownloadContent.tsx` | Sub-tabs for HuggingFace browser and local file add |
| `RecommendedModel.tsx` | The hardware-sized suggestion `gglib up` makes on a first run, surfaced where models are chosen |
