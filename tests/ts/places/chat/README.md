# tests/ts/places/chat

The chat place, rendered on its own under the place providers with the
transport stubbed (`chatPlaceHarness.tsx`), or inside the shell over the real
routes (`chatPlaceInShell.test.tsx`). The routes that pick its conversation
and model are `tests/ts/app/chatRoutes.test.tsx`'s; the sidebar's list is
`tests/ts/sidebar/chatList.test.tsx`'s. Each test is checked by deleting the
production line it pins and watching it go red.

| File | Pins |
|------|------|
| `chatPlaceHarness.tsx` | Not a test: the transport stub (the model's facts and its template support among its answers), providers and jsdom patches the chat tests share, the chat store emptied before each; `ChatPlaceWithList`, the place beside a stand-in for the sidebar's list whose click hands it another conversation; `fromTitleMenu` |
| `chatPlaceInShell.test.tsx` | The sidebar's + opens an empty chat with no dialog; its first send's conversation replaces the address and is the sidebar's marked row; leaving for the library unloads nothing |
| `ChatPlaceTitleMenu.test.tsx` | The title ▾: the title is the menu button, its items in order with Delete… apart; Rename; Generate title greyed with why where nothing serves the chat; Export; Start over asks, then opens an empty copy with the same title and prompt; Delete… asks and hands up the delete; an empty chat's title is plain. The system prompt line: nothing for the default; System prompt… opens the editor above the first turn; Save makes the line; Edit, Cancel, Reset to default saving none |
| `ChatPlaceNotebook.test.tsx` | The place as a notebook: a saved reply's margin shows the figures it has and none it lacks, reads who → body → how it was made, opens its detail; a reply arriving shows its prompt progress; a turn of only a tool call or only reasoning shows it; the composer names the model and quantisation, as text or as a picker, and its tools popout grows rightwards; the context ring from the last reply's figures, its sentence and detail, its warning and danger thresholds, kept through a stopped reply, each chat's own |
| `ChatPlaceModelPicker.test.tsx` | The composer's model picker: running servers, then models that are not; the current model listed once; a choice handed up with the conversation open when the switch lands; a failed start toasted; a place given a conversation opens on it; the unsent text handed up and put back; locked across a change of conversation while a model starts |
