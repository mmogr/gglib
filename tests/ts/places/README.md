# places

Tests that drive a place by its address or by a click, through the real routes and providers, and assert on the screen that comes up.

| File | Renders |
|------|---------|
| `harness.tsx` | Not a test: `renderApp(path)`, the app's routes under its providers over a memory router started at `path`, made the app's router so the menu bridge reaches it |
| `library.test.tsx` | The library place: Downloading, Loaded, On this Mac and the paired machine's group in that order, a model in one; a loaded row's word from the launch state the server list gives, re-read after a load's event; the facts under a name and a missing part as the one accessory; search as you type and the sentence when nothing matches; Sort; the paired group's reach from the remote status; the empty, failed (with Retry) and loading states; downloads in their rows' words, cancelled and taken off the queue; a pick that changes only the row's fill and opens the inspector; Unload and copying the Model ID; the Add pane at its address with the way back; the llama.cpp banner's update, refusal, install and Not now |
| `libraryGroups.test.ts` | `places/library/groups`: a model in one group; a search's words all matching the name, quant, a tag, the architecture, what a model can do, or a size word by the parameter count; the far rows' and the downloads' matching; the sorts, an unmeasured model last by speed either way |
| `libraryChat.test.tsx` | The library as the way into a chat, with `ChatPage` a placard: a far row's inspector opens a chat with the paired machine's model with nothing served here, and closing it stops nothing and offers no Unload; the same model on both machines is two rows and picking either clears the other; a far read that never answers leaves this machine's rows working; closing a local chat leaves its model loaded, and its Unload stops that model with the chat left open; Open chat only while a model runs; the composer's switch serves a model not running (and not one that is) and remounts the chat on it with the conversation open when it lands; a Close while the model starts stays closed, a reopened chat gets no stale switch, the last pick lands, the page is told which model is starting, a failed start leaves the chat; a cold `?serve=1` opens the Serve dialog once; removing the selected model takes the address back to the library; the inspector's projector and component pickers; and a desktop window queues a download from the Add pane with no event from its shell |
