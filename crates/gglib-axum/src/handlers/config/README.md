# config

<!-- module-docs:start -->

Configuration and system management handlers.

Settings, system setup, llama.cpp installation, and the image runtime
(stable-diffusion.cpp's `sd-server`: install over SSE with llama.cpp's event
names, status, and removal, refused while an image model runs). An install
and a removal take one slot, so neither starts while the other runs.
