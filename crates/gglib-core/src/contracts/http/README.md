# http

<!-- module-docs:start -->

HTTP route constants; `daemon_bodies`, the keys of the request bodies the CLI
sends the daemon; `path_segment`, which encodes a model identifier as one
path segment for the routes that take one; `MAX_BODY_BYTES`, the body
limit of the proxy routes that take images; and `attachments`, where an
image a message carries is sent and read by its id.
